# EV_Dashboard_Portfolio

# ⚡ Electric Vehicle Population Analysis

Electric Vehicle Population Analysis is an interactive data analytics dashboard designed to analyze electric vehicle registrations, vehicle types, manufacturers, model years, states, and CAFV eligibility.

## 🚀 Project Overview

This project provides insights into electric vehicle registration data from the Washington State Department of Licensing.

The dashboard analyzes **130,816 registered electric vehicles** and presents the data through interactive charts, KPIs, and tables.

## 📊 Key KPIs

- ⚡ Total Vehicles: 130,816
- 🔋 Avg Electric Range: 73.1 mi
- 🚗 Total BEV: 104,850
- 🔌 Total PHEV: 25,966

## 📈 Dashboard Features

### 1. Vehicles by Model Year

Displays the number of electric vehicles registered by their first model year.

This visualization helps identify:

- Growth of EV adoption over time
- Years with the highest registrations
- Changes in EV registrations across model years

### 2. CAFV Eligibility

Shows the Clean Alternative Fuel Vehicle (CAFV) eligibility status of registered vehicles.

Categories include:

- Eligible
- Unknown
- Not Eligible

### 3. Top Makes

Displays the leading electric vehicle manufacturers based on the number of registered vehicles.

Top manufacturers include:

- Tesla
- Nissan
- Chevrolet
- Ford
- BMW
- Kia
- Toyota
- Volkswagen
- Volvo
- Jeep

### 4. Top States

Shows the states where the electric vehicles are registered.

The dashboard highlights:

- Washington
- California
- Virginia
- Texas
- Colorado
- Maryland
- Arizona
- Florida

### 5. Top Models

Provides a detailed table of the most registered electric vehicle models.

The table includes:

- Model
- Make
- Vehicle Type
- Number of Vehicles
- Market Share

Examples include:

- Tesla Model Y
- Tesla Model 3
- Nissan Leaf
- Tesla Model S
- Chevrolet Bolt EV
- Tesla Model X
- Chevrolet Volt
- Volkswagen ID.4
- Ford Mustang Mach-E
- Toyota Prius Prime
